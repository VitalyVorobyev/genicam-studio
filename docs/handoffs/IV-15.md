# IV-15: Line Profile

## Spec

**What:** A toggleable line-draw mode on the image canvas — drag to place a line segment, then a floating panel renders the pixel intensity profile along that line (grayscale or per-channel R/G/B, refreshed at ~5 fps).
**Why:** Core image analysis tool for machine vision engineers; completes the M4 Image Viewer milestone.

- `ui/genicam-studio-ui/src/components/ImageViewer/lineProfileUtils.test.ts` — new: unit tests for all three pure functions

**Key decisions:**
- Drag interaction mirrors IV-14 ROI exactly: pointer-down sets start, drag updates live overlay line, pointer-up computes image-space `LineSegment` via `mouseToImageCoordsClamped` and emits via `onLineSelect`
- `lineMode` takes priority over `roiMode` in `ViewerCanvas` pointer handler selection; only one draw mode active at a time (managed in `ImageViewer`)
- Profile is sampled directly from BMP bytes (same approach as `computeHistogram`); reads bpp/offset from BMP header; `bresenhamLine` walks image-space pixels
- `LineProfilePanel` is inside `.iv-canvas-wrap` at bottom-left (260×80px), mirroring histogram overlay at bottom-right — both panels can be open simultaneously
- `lineSegment` (image-space) is round-tripped: emitted from `ViewerCanvas` → stored in `ImageViewer` → passed back to `ViewerCanvas` for the `LineProfilePanel`; this keeps panel data out of canvas internal state
- `renderLineProfile` uses `ctx.beginPath()` + `lineTo` polyline (not bars like histogram), normalised 0–255 → canvas height
- Lines with fewer than 2 pixels render as empty (no draw)

# MS-10: Multi-Format Synthetic Images

## Spec

**What:** Add Mono16, BayerRG8, RGB8 synthetic image generators to the mock service and dispatch on the current PixelFormat node value per frame.
**Why:** The mock service only generated Mono8. Multi-format is needed to test streamer format detection (ST-01, ST-02) and image viewer rendering (IV-17).

**Files touched:**
- `apps/genicam-mock-service/src/acquisition.rs` — add three generator functions + format dispatch in frame tick arm

**Key decisions:**
- Mono16: little-endian u16 via `to_le_bytes()`, horizontal gradient + vertical sine wave for recognizable pattern
- BayerRG8: RGGB tile with independent R/G/B channel animations — debayered output should show colour
- RGB8: packed R/G/B animated at different speeds — should cycle through hues
- Unknown/Mono12/other formats fall back to Mono8 via wildcard arm
- No fixture XML change needed — all required formats already in the PixelFormat enum entries

**Unit tests required:** None — generators are pure but produce large buffers; tested by build + smoke test

**CHANGELOG entry:** `- MS-10: Multi-format synthetic image generators (Mono16, BayerRG8, RGB8) in mock service`

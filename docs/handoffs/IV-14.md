# IV-14: ROI Selection Tool

## Spec

**What:** A toggleable ROI draw mode on the image canvas — drag to select a rectangle, then click "Apply ROI" in the toolbar to write Width/Height/OffsetX/OffsetY to the device.
**Why:** Enables engineers to visually define the camera ROI directly on the live image instead of manually typing pixel offsets.

**Files touched:**

- `ui/genicam-studio-ui/src/components/ImageViewer/roiUtils.test.ts` — new: unit tests for all pure functions

**Key decisions:**
- When `roiMode` is true, pointer drag on canvas draws ROI rect instead of panning; wheel zoom stays active in all modes
- ROI overlay position is tracked in wrap-relative screen space (for SVG rendering); image-space coords computed on pointer-up via `mouseToImageCoordsClamped`
- `roiOverlayRect` state lives in `ViewerCanvas` (screen-space, drives SVG); `roiRect: ImageRect | null` lives in `ImageViewer` (image-space, drives apply)
- Clearing ROI: toggling roiMode off resets both overlay and stored rect; starting a new drag replaces the existing selection
- Apply ROI: writes Width then Height then OffsetX then OffsetY sequentially; only available when Tauri context present (`isTauri()`)
- `mouseToImageCoordsClamped` added to `viewerUtils.ts` since it's a coordinate utility parallel to `mouseToImageCoords`

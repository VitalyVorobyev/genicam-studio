# IV-13: Histogram

## Spec

**What:** Live histogram overlay on the Image Viewer canvas — grayscale for Mono formats, per-channel R/G/B for color; toggled via a toolbar button.
**Why:** Core image analysis tool for machine vision engineers; last remaining L-size M4 task before ROI selection (IV-14).

**Files touched:**
- `ui/genicam-studio-ui/src/components/ImageViewer/histogramUtils.ts` — new: pure `computeHistogram` (BMP-aware) and `renderHistogram` functions
- `ui/genicam-studio-ui/src/components/ImageViewer/histogramUtils.test.ts` — new: unit tests for both pure functions
- `ui/genicam-studio-ui/src/components/ImageViewer/HistogramOverlay.tsx` — new: floating overlay component, polls `snapshotRef` at ~5fps via `setInterval`
- `ui/genicam-studio-ui/src/components/ImageViewer/ViewerToolbar.tsx` — add histogram toggle button (▤) and `showHistogram`/`onToggleHistogram` props
- `ui/genicam-studio-ui/src/components/ImageViewer/ViewerCanvas.tsx` — add `showHistogram` prop, render `HistogramOverlay` inside the canvas wrap
- `ui/genicam-studio-ui/src/components/ImageViewer/ImageViewer.tsx` — add `showHistogram` state, wire toggle
- `ui/genicam-studio-ui/src/styles/components.css` — `.iv-histogram` and `.iv-histogram__canvas` styles

**Key decisions:**
- Histogram reads directly from BMP header bytes (same as `samplePixel`) — no extra image-size props needed; `computeHistogram(bmpBytes)` is self-contained
- Refresh via `setInterval(200ms)` in `HistogramOverlay` — avoids coupling to the WebSocket frame rate
- Placed inside `.iv-canvas-wrap` (already `position: relative; overflow: hidden`) — bottom-right corner, 204×100px panel
- 8bpp BMP → single white channel; 24bpp BMP → R/G/B channels drawn with semi-transparent fills (additive blending)
- No external charting library; rendered onto a `<canvas>` element

**Unit tests required:**
- `test_computeHistogram_gray8_all_same` in `histogramUtils.test.ts` — 2×2 uniform image, bin[v]=4
- `test_computeHistogram_gray8_two_values` in `histogramUtils.test.ts` — half pixels at 0, half at 255
- `test_computeHistogram_gray8_row_stride_padding` in `histogramUtils.test.ts` — odd-width image counts correctly
- `test_computeHistogram_rgb24_channels` in `histogramUtils.test.ts` — 1×1 R=255 G=128 B=64 pixel, correct bin
- `test_computeHistogram_too_short` in `histogramUtils.test.ts` — < 54 bytes → null
- `test_computeHistogram_unsupported_bpp` in `histogramUtils.test.ts` — 32bpp header → null
- `test_renderHistogram_mono_peak_fills_height` in `histogramUtils.test.ts` — peak bin reaches canvas height
- `test_renderHistogram_rgb_draws_three_channels` in `histogramUtils.test.ts` — no throw for rgb data

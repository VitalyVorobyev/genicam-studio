# UX-03: Device Sidebar Polish

## Spec

**What:** Polish the Device Sidebar with per-card connection state dots, a connecting-state animation on device cards, an animated scanning indicator for the empty state, device count in the section header, and design-token-based disconnect banner.
**Why:** Makes connection status immediately readable at a glance without requiring the user to inspect the global conn-badge in the header.

**Files touched:**
- `ui/genicam-studio-ui/src/components/DeviceSidebar/DeviceCard.tsx` — add `device-card__header` wrapper with name + state dot; apply `device-card--connecting` class
- `ui/genicam-studio-ui/src/components/DeviceSidebar/DeviceSidebar.tsx` — show device count in section header; replace plain empty text with animated scanning component; use design tokens in disconnect banner
- `ui/genicam-studio-ui/src/styles/components.css` — new CSS for status dot, connecting animation, scanning dots animation, token-based banner

**Key decisions:**
- Status dot goes inside the card header (right-aligned next to name), mirroring the `app-header__device-dot` pattern already in the header chip
- Connected card gets a green dot + pulsing border animation for the connecting state (border alternates between `--warning-border` and `--warning`)
- Empty state replaced with three bouncing scan dots (staggered delay) + "Scanning for devices…" label — avoids a heavy loading skeleton for a simple scan state
- Device count shown as a dimmed `(N)` pill after the "Devices" label — only when N > 0
- Disconnect banner: raw `rgba()` values replaced with `var(--danger-muted)`, `var(--danger-border)`, `var(--danger)`, `var(--danger-border)` from tokens

**Unit tests required:** none — no new pure functions introduced

**CHANGELOG entry:** `- UX-03: Device sidebar polish — per-card state dots, connecting animation, animated scan indicator, device count badge`

# CI-01: End-to-end Integration Tests

## Spec

**What:** Add a `lib.rs` to `genicam-mock-service` to expose its modules, then write four `#[tokio::test]` integration tests that spin up mock service tasks in-process over a real Zenoh peer-to-peer session to assert the full wire protocol.

**Why:** Gives the CI pipeline automated verification that discovery, XML fetch, node read/write, and bulk read all work end-to-end through the shared Zenoh API types without real hardware.

**Files touched:**
- `apps/genicam-mock-service/src/lib.rs` — NEW: `pub mod` re-exports for all 8 service modules
- `apps/genicam-mock-service/src/config.rs` — remove `from_cli` (uses `crate::Cli` from `main.rs`); add direct struct constructor
- `apps/genicam-mock-service/src/main.rs` — remove `mod` declarations; import from `genicam_mock_service::*`; construct `MockConfig` via new constructor
- `apps/genicam-mock-service/tests/integration.rs` — NEW: 4 integration tests

**Key decisions:**
- Use in-process Zenoh sessions (peer-to-peer default config) rather than spawning a subprocess — avoids build-order complexity and is faster.
- Each test uses a unique `device_id` (e.g. `"ci01-discovery"`, `"ci01-xml"`) so concurrent tests don't interfere with each other's subscriptions.
- 200 ms sleep after queryable registration to ensure Zenoh peer routing is ready before issuing queries.
- 10-second `tokio::time::timeout` wrappers on all async receive operations to fail fast in CI.
- `#[tokio::test(flavor = "multi_thread", worker_threads = 2)]` so spawned service tasks run concurrently with the test body.

**Unit tests required:**
- `test_discovery_announcement` in `tests/integration.rs` — subscribe before starting service; assert announce fields and `api_version == Some(1)`
- `test_xml_queryable` in `tests/integration.rs` — fetch XML, assert it contains `<RegisterDescription`
- `test_bulk_read_queryable` in `tests/integration.rs` — request Width+Height, assert values match config (320×240)
- `test_node_set_queryable` in `tests/integration.rs` — set Width=512, assert `ok=true` and stored value updated

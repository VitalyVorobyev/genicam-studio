# TB-04: Node Value Validation

## Spec

**What:** Validate node writes in the `write_node` Tauri command against UiGraph constraints (access mode, type compatibility, numeric range, increment, enum membership) before sending to the camera service.

**Why:** Provides immediate, local error feedback to the UI and prevents invalid values from reaching the hardware, reducing round-trips and protecting the camera.

**Files touched:**
- `apps/genicam-studio-tauri/src-tauri/src/commands/nodes.rs` — add `validate_node_write` + `validate_numeric_constraints` pure functions; add `ModelState` read parameter to `write_node`

**Key decisions:**
- Validation is **best-effort / soft-fallback**: if `ModelState` has no loaded graph, or the node is not found in the graph, the write passes through unchanged. This avoids blocking writes during edge cases (e.g., fast writes before XML fully loads).
- Runtime constraints from `NodeValueEntry` (ZA-06) take priority over static XML constraints; static `NumericConstraints` from UiGraph are the fallback.
- Increment check uses `(value − base) % inc` with a 1e-9 floating-point epsilon to handle rounding.
- Command nodes are explicitly rejected with a helpful error suggesting `execute_command`.
- Category, Register, and Unknown nodes are rejected as non-writable.

**Unit tests required:**
- `test_validate_node_write_integer_valid` in `nodes.rs` — integer in range passes
- `test_validate_node_write_integer_above_max` in `nodes.rs` — value > max returns error
- `test_validate_node_write_integer_below_min` in `nodes.rs` — value < min returns error
- `test_validate_node_write_integer_wrong_type` in `nodes.rs` — string value for Integer returns error
- `test_validate_node_write_float_valid_with_runtime_constraints` in `nodes.rs` — runtime min/max take precedence
- `test_validate_node_write_boolean_wrong_type` in `nodes.rs` — non-bool returns error
- `test_validate_node_write_enumeration_valid` in `nodes.rs` — known entry passes
- `test_validate_node_write_enumeration_invalid_entry` in `nodes.rs` — unknown entry returns error
- `test_validate_node_write_readonly_access_mode` in `nodes.rs` — RO node returns error
- `test_validate_node_write_command_rejected` in `nodes.rs` — Command kind returns error
- `test_validate_numeric_constraints_inc_violation` in `nodes.rs` — value not on increment grid returns error
- `test_validate_numeric_constraints_no_constraints` in `nodes.rs` — no constraints passes any value

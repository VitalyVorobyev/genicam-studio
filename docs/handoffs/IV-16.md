# IV-16: Snapshot Save

## Spec

**What:** Save the current full-resolution camera frame as a PNG file via a native file-save dialog (Tauri) or a browser download link (WASM mode), triggered by the existing toolbar `⊙` button.

**Why:** Gives machine vision engineers a one-click way to capture a reference frame for offline analysis, defect review, or documentation without needing a separate tool.

**Key decisions:**
- PNG encoding uses an `OffscreenCanvas` in the browser main thread (`convertToBlob`), avoiding any native Rust encoder dependency; a `document.createElement("canvas")` fallback covers environments where `OffscreenCanvas` is absent.
- `@tauri-apps/plugin-dialog` and `@tauri-apps/plugin-fs` are imported with dynamic `import()` inside the Tauri branch of `snapshotSave.ts` so they are never loaded in browser/WASM mode, keeping the browser build clean.
- `lastFrameRef` stays internal to `ViewerCanvas` (pixel inspector depends on it); the parent-owned `snapshotRef` receives the same `Uint8Array` reference on each frame — no copy.
- `Mono16` and Bayer formats are converted to 8-bit grayscale best-effort (high byte for Mono16; gray from single byte for Bayer) with a doc-comment linking to ST-02. Unknown formats return `null` from `frameToImageData` and produce a silent no-op snapshot.
- The `⊙` button is enabled only when `onSnapshot` is defined (i.e., a canvas is active); the no-streamer early-return path in `ImageViewer` omits `onSnapshot`.

### Important Issues

**`window.__TAURI__` check in a non-provider file**

File: `ui/genicam-studio-ui/src/components/ImageViewer/snapshotSave.ts`, line 14

```ts
if (typeof window !== "undefined" && "__TAURI__" in window) {
```

The project invariant (AGENTS.md / CLAUDE.md) states that `window.__TAURI__` direct calls must be confined to provider files. The canonical pattern is the `isTauri()` helper in `ui/genicam-studio-ui/src/tauri.ts`, which is already used by `provider.ts`. `snapshotSave.ts` is not a provider file — it is a utility that is also imported by `ImageViewer.tsx`.

Impact is low because the check is wrapped in `typeof window !== "undefined"` (safe for SSR), uses `"__TAURI__" in window` (not a bare property read), and the dynamic `import()` of Tauri plugins below it is already correct. However it duplicates the detection logic and places it outside the designated boundary.

Suggested fix: import `isTauri` from `../../tauri` (or a relative path to `src/tauri.ts`) and replace the inline check with `if (isTauri()) {`. This brings it in line with the provider pattern without any other code change.

Confidence: 85%.

# UX-04: Feature Browser Polish

## Spec

**What:** Polish the Feature Browser with kind-colored icons in the tree, a clear button in the search input, kind indicator icons added to search result rows, and category row visual distinction.
**Why:** Makes the tree immediately scannable by feature type (Integer/Float/Enum/Boolean/Command) without requiring a click to view the kind badge in the detail panel.

**Files touched:**
- `ui/genicam-studio-ui/src/xml_model/helpers.ts` — add exported pure function `nodeKindCssKey(kind): string` mapping kind to CSS key; add `nodeKindIcon(kind): string`
- `ui/genicam-studio-ui/src/xml_model/helpers.test.ts` — new: unit tests for `nodeKindCssKey` and `nodeKindIcon`
- `ui/genicam-studio-ui/src/components/FeatureBrowser/CategoryTreeNode.tsx` — import and use `nodeKindCssKey`/`nodeKindIcon` from helpers; add `tree-item--category` class to category rows; apply `tree-item__icon--{key}` to leaf icon spans
- `ui/genicam-studio-ui/src/components/FeatureBrowser/FeatureBrowserPage.tsx` — add icon span to `SearchResults` items; add search clear (×) button inside search wrapper
- `ui/genicam-studio-ui/src/styles/components.css` — `.tree-item__icon--*` color classes; `.tree-item--category` label weight; `.browser-toolbar__search-clear` button

**Key decisions:**
- `nodeKindCssKey` and `nodeKindIcon` move to `helpers.ts` (not duplicated per component) — they're presentation-pure and used in both tree and search
- The existing local `kindIcon()` in `CategoryTreeNode.tsx` is replaced by the exported `nodeKindIcon` from helpers
- The existing `kind-badge` CSS (already colored per kind in FeaturePanel) is NOT reused inline in the tree — instead a lighter approach: just color the ASCII icon span; this keeps tree rows compact
- Search clear button uses absolute positioning inside the existing `position: relative` search wrapper — no markup restructuring needed
- No functional behavior change: tree expand/collapse, keyboard nav, visibility filter, drafts remain untouched

**Unit tests required:**
- `test_nodeKindCssKey_integer` in `helpers.test.ts` — "Integer" → "integer"
- `test_nodeKindCssKey_float` in `helpers.test.ts` — "Float" → "float"
- `test_nodeKindCssKey_enumeration` in `helpers.test.ts` — "Enumeration" → "enum"
- `test_nodeKindCssKey_command` in `helpers.test.ts` — "Command" → "command"
- `test_nodeKindCssKey_unknown_object` in `helpers.test.ts` — `{Unknown:{tag:""}}` → "unknown"
- `test_nodeKindIcon_integer` in `helpers.test.ts` — "Integer" → "#"
- `test_nodeKindIcon_command` in `helpers.test.ts` — "Command" → ">"
- `test_nodeKindIcon_unknown` in `helpers.test.ts` — unknown kind → "·"

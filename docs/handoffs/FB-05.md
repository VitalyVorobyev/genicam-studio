# FB-05: Export Full Node State

## Spec

**What:** An "Export State" button in the Feature Browser toolbar that downloads the full set of current live device values (not just drafts) as a JSON preset file, using the same format importable by the existing "Import Preset" action.
**Why:** Allows engineers to snapshot the complete device configuration at any moment and restore it later — essential for saving calibrated settings before changing experimental parameters.

**Files touched:**
- `ui/genicam-studio-ui/src/components/FeatureBrowser/presetUtils.ts` — new: `buildLiveValuePreset(liveValues)` pure function
- `ui/genicam-studio-ui/src/components/FeatureBrowser/presetUtils.test.ts` — new: unit tests for `buildLiveValuePreset`
- `ui/genicam-studio-ui/src/components/FeatureBrowser/FeatureBrowserPage.tsx` — add `onExportLiveState` callback; add "Export State" button next to "Export Preset"; disable when no live values

**Key decisions:**
- Export format is identical to the existing draft-preset format (`Record<string, value>`) so the result can be imported with the existing "Import Preset" and then "Apply All" (FB-02) to restore the device state
- All live values are exported regardless of access_mode — filtering to writable-only is not done at export time since the same preset file might be used with a different device where access modes differ
- The exported file is named `genicam-state.json` (static, no timestamp) to distinguish from `genicam-preset.json` and match the existing naming convention
- `buildLiveValuePreset` is a pure function that converts `Map<string, NodeValueEntry>` to `Record<string, number|string|boolean>`, extracting only the `.value` field
- The "Export State" button is disabled when `liveValues` is empty (not connected or no live data loaded)

**Unit tests required:**
- `test_buildLiveValuePreset_empty` in `presetUtils.test.ts` — empty map → `{}`
- `test_buildLiveValuePreset_numbers` in `presetUtils.test.ts` — numeric entries preserved

- `test_buildLiveValuePreset_booleans` in `presetUtils.test.ts` — boolean entries preserved
- `test_buildLiveValuePreset_mixed` in `presetUtils.test.ts` — mixed types all preserved

# UX-05: Image Viewer Chrome

## Spec

**What:** Polish the Image Viewer toolbar, status bar, and canvas container into a professional instrument-panel chrome — device name in toolbar, interactive zoom controls, fps warning, and state-aware canvas framing.
**Why:** The IV-01/IV-11/IV-12 scaffolding is functional but visually minimal; UX-05 makes the Image Viewer look and feel like a desktop instrument rather than a prototype.

**Files touched:**
- `ui/genicam-studio-ui/src/styles/tokens.css` — add `--iv-statusbar-bg` token (slightly darker than `--bg-elevated`)
- `ui/genicam-studio-ui/src/styles/components.css` — toolbar icon-button style, zoom badge interactive style, canvas idle/active shadow states, status bar background, fps warning class, toolbar spacer
- `ui/genicam-studio-ui/src/components/ImageViewer/ViewerToolbar.tsx` — add `deviceName?`, `onResetZoom` props; add fit-to-window icon button; make zoom badge a clickable button; add disabled snapshot placeholder button
- `ui/genicam-studio-ui/src/components/ImageViewer/ViewerStatusBar.tsx` — add `fpsWarnBelow?: number` prop (default 10); apply `iv-statusbar__fps--warn` class when fps is below threshold
- `ui/genicam-studio-ui/src/components/ImageViewer/ViewerCanvas.tsx` — add `resetZoomRef?: React.RefObject<(() => void) | null>` prop (populates it with the dispatch-RESET callback); add `isStreaming: boolean` prop for idle/active wrap class
- `ui/genicam-studio-ui/src/components/ImageViewer/ImageViewer.tsx` — add `deviceName?: string` to props; create `resetZoomRef` and stable `handleResetZoom`; thread both into toolbar and canvas; apply `iv-canvas-wrap--idle` on the no-streamer path
- `ui/genicam-studio-ui/src/components/Layout/AppLayout.tsx` — pass `deviceName={connectedDeviceName ?? undefined}` to `ImageViewer`
- `CHANGELOG.md` — add entry under `[Unreleased]`

**Key decisions:**
- `resetZoom` is exposed from `ViewerCanvas` via a `RefObject` rather than a prop callback going the other direction, because `useZoomPan` lives inside `ViewerCanvas` and its `dispatch` is not accessible to the parent otherwise. The ref is populated in a `useEffect` and the parent calls it imperatively — this is the same pattern as imperative handle but without `forwardRef`/`useImperativeHandle`, keeping the component API surface minimal.
- The zoom badge becomes a `<button>` element (not a `<span>`) so it is keyboard-accessible and semantically correct as an interactive control.
- `fpsWarnBelow` is an optional prop defaulting to 10 inside the component, not a hardcoded constant, so callers can override it without a component change.
- The snapshot button is `disabled` with no `onClick`; it is a UI placeholder only — no state, no handler. Its presence establishes the toolbar slot for IV-16 (Snapshot save).
- Unicode symbol for fit-to-window: `⤢` (U+2922). Implementer must visually verify rendering; fallback to `[ ]` text if the glyph does not display clearly.
- `--iv-statusbar-bg: #0f1318` — one step darker than `--bg-elevated` (`#1c2128`), making the status bar visually distinct from the canvas above it.
- Idle canvas state uses `box-shadow: inset 0 0 0 1px var(--border-subtle), inset 0 2px 8px rgba(0,0,0,0.4)` to delineate the canvas area without adding a hard border. Active state removes the shadow (`box-shadow: none`).

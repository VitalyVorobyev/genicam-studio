# Task Handoffs

One file per implemented backlog task. Each file records the architect's spec, implementer's report, and reviewer's verdict — the full decision trail for a task.

## Format

```
{TASK_ID}.md
  ## Spec          ← architect writes: what, why, files, decisions
  ## Implementation ← implementer writes: files changed, tests added, deviations
  ## Review         ← reviewer writes: gate results, issues, verdict
```

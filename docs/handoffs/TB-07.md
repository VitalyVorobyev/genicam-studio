# TB-07: Streamer Lifecycle Improvement

## Spec

**What:** Adds health monitoring of the `genicam-ws-streamer` child process: a dedicated monitor task watches
the child, auto-restarts it on unexpected crash (up to 5 times, 500 ms backoff), and emits a
`streamer-status` Tauri event so the UI can observe the streamer state.

**Why:** The current implementation spawns the streamer once and forgets it; a crash silently breaks the
live image view with no feedback to the user and no recovery.

**Files touched:**
- `apps/genicam-studio-tauri/src-tauri/src/state/device_state.rs` — add `StreamerStatus`; replace
  `child: Option<Child>` in `AcquisitionInner` with `stop_tx` + `monitor_handle`
- `apps/genicam-studio-tauri/src-tauri/src/commands/acquisition.rs` — add `StreamerArgs`,
  `build_streamer_args`, `spawn_streamer_child`, `run_streamer_monitor`; refactor `start_acquisition`
  and `stop_acquisition_child`
- `docs/zenoh-api.md` — add `streamer-status` event row to the Tauri Events table
- `CHANGELOG.md` — add TB-07 entry under `[Unreleased]`

**Key decisions:**
- Monitor task owns the child `Child` value; stop is signalled via a `tokio::sync::watch` channel
  (`Sender<bool>` stored in `AcquisitionInner`) so the task can kill the child cleanly before exiting.
- `child: Option<tokio::process::Child>` is removed from `AcquisitionInner`; replaced by `stop_tx` and
  `monitor_handle`.
- Max 5 restart attempts with a fixed 500 ms delay between restarts; after the limit the monitor task
  exits and a final `streamer-status { running: false, error: "max restarts exceeded" }` is emitted.
- Pure helper `build_streamer_args` extracts the args-list construction so it can be unit-tested without
  spawning a real process.
- `stop_acquisition_child` signature unchanged (takes `&ZenohState`); callers in `device.rs` need no
  modification.

**Unit tests required:**
- `fn test_build_streamer_args_contains_image_key` in `acquisition.rs` — verifies `--image-key` arg present
- `fn test_build_streamer_args_contains_bind` in `acquisition.rs` — verifies `--bind` arg includes port

**CHANGELOG entry:** `- TB-07: Streamer lifecycle improvement — monitor task with auto-restart (≤5 retries) and streamer-status Tauri event`

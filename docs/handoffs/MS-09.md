# MS-09: Image Metadata Publisher

## Spec

**What:** Publish `ImageMeta` JSON to `genicam/devices/{id}/image/meta` on acquisition start and whenever Width, Height, or PixelFormat node values change.
**Why:** Enables the streamer (ST-01) and Tauri backend (TB-01) to auto-configure without CLI `--width`/`--height` arguments.

**Files touched:**
- `apps/genicam-mock-service/src/acquisition.rs` — add helpers + new select! arm + metadata publish on Start

**Key decisions:**
- `parse_pixel_format` uses `serde_json::from_value` + `#[serde(other)]` fallback — never panics on unknown strings
- Publish on node change only while actively acquiring (`*acq_rx.borrow()` guard)
- `Closed` channel error logs a warning before breaking (observable shutdown path)

**Unit tests required:** None — all new functions are async or depend on NodeStore

**CHANGELOG entry:** `- MS-09: Image metadata publisher — publishes ImageMeta JSON to {id}/image/meta on acquisition start and on Width/Height/PixelFormat change`

# IV-05: Trigger Configuration Section

## Spec

**What:** Add a `TriggerSection` component to the Image Viewer `ControlSidebar` that renders controls for `TriggerMode`, `TriggerSource`, `TriggerActivation` (each an enum `<select>`) and `TriggerDelay` (float slider + text input), replacing the generic placeholder for the `"trigger"` group.

**Why:** The `"trigger"` group in `sfnc-groups.json` already appears in the sidebar (via IV-09's data-driven rendering) but renders a "future update" placeholder; this task delivers the real controls, completing the core trigger workflow for machine vision engineers who use hardware or software triggering.

**Files touched:**
- `ui/genicam-studio-ui/src/components/ImageViewer/triggerUtils.ts` — new pure utility module: `formatTriggerDelayLabel`, `resolveLiveEnumValue`; re-exports `extractNumericConstraints` and `clampValue` from `exposureGainUtils`
- `ui/genicam-studio-ui/src/components/ImageViewer/triggerUtils.test.ts` — vitest unit tests for all functions in `triggerUtils.ts`
- `ui/genicam-studio-ui/src/components/ImageViewer/TriggerSection.tsx` — new React component with same props as `ExposureGainSection`: `isConnected`, `externalModel`, `liveValues`
- `ui/genicam-studio-ui/src/components/ImageViewer/ControlSidebar.tsx` — import `TriggerSection`; add `case "trigger":` to `renderSectionContent`
- `CHANGELOG.md` — add entry under `[Unreleased]`

**Key decisions:**
- Each of the four controls is independently gated on node presence in UiGraph (`enum_entries.length > 0` for enums; `nodes?.["TriggerDelay"] !== undefined` for the slider) — a camera missing any node renders that control invisible, not broken.
- Reuse existing CSS classes (`exp-gain-section`, `if-enum-row`, `iv-auto-select`, `slider-row`, `iv-slider`, `iv-text-input`) without adding new styles; the section is visually indistinguishable from existing sections.
- `TriggerDelay` uses `step="any"` on the slider because the XML node has no `<Inc>` element (`extractNumericConstraints` returns `inc: 0`), matching the `ExposureTime` float pattern.
- `writeNode` is a module-private Tauri-gated async function (identical pattern to `ExposureGainSection`); no new IPC command is needed.
- Draft state + dragging ref pattern (pointer-down sets ref true, pointer-up clears + writes, text blur also writes) is copied exactly from `ExposureGainSection` for `TriggerDelay`.
